# Encoder-attack

针对图像编码器模型应用场景，本文设计了一种基于替代编码器的无数据黑盒对抗样本生成方法。该方法在少样本条件下，通过对比学习对替代编码器进行预训练，有效提升其特征表示能力。随后，采用对抗样本对齐技术来微调替代编码器，从而在不断拟合目标编码器决策边界的同时，提高模型决策边界的平滑性，增强对抗样本的迁移能力。通过在四个图像数据集上的对比实验，验证了本方法在有限的查询次数下生成的对抗样本使下游任务模型产生误判，攻击效果优于对比方法。

## 项目结构
### 关键文件和目录
- `data/` : 存放数据集
- `datasets`: 数据集预处理
- `evaluation`: 对抗样本性能测试
- `models`: 模型
- `scripts`: 脚本
- `encoder_datafree_attack`: 无数据黑盒对抗攻击主文件
### 脚本
- `run_encoder_attack.py`: 进行无数据黑盒对抗样本攻击的脚本
- `run_training_downstream_classifier.py`: 训练下游分类器
